Value Change Dump (VCD) — текстовый формат, в котором симуляторы аппаратуры записывают, как сигналы меняются во времени; GTKWave и другие программы просмотра рисуют его в виде временных диаграмм. В 2017 году я перенёс на C++ Python-библиотеку [pyvcd](https://github.com/SanDisk-Open-Source/pyvcd). В 2026-м я запустил её под AddressSanitizer и UndefinedBehaviorSanitizer и нашёл переполнение буфера в куче, разыменование нулевого указателя, деструктор, бросающий исключение, и некорректный VCD на выходе — всё это пряталось за 18 проходящими тестами, потому что эталонный файл, с которым они сравнивали вывод, закрепил неправильный результат. После исправлений в библиотеке 39 тестов, а переписанный горячий путь ускорил `change()` [в 2–5 раз](https://github.com/favorart/vcd-writer/pull/10).

## Что внутри

- **Стандарт, проверенный пункт за пунктом.** VCD с четырёхзначной логикой из IEEE 1364-2005 §18.2: заголовок, вложенные области видимости, все 18 типов переменных, скалярные, векторные и вещественные значения, `$dumpvars`, `$dumpoff` / `$dumpon`; строковые значения — как расширение GTKWave. В README есть таблица: что поддерживается, а что нет.
- **Ни одного выделения памяти на изменение.** Значения форматируются в буфер на 64 КиБ и записываются одним вызовом; бенчмарк лежит прямо в репозитории.
- **Проверки без побочных эффектов.** Имена, размеры, значения и дата проверяются до того, как что-либо изменится, поэтому неудачный вызов не оставляет в файле следов; метка времени из прошлого приводит к исключению.
- **Детерминированный вывод за компактным интерфейсом.** Файл получается побайтно одинаковым на любой платформе; внутреннее состояние спрятано за pimpl, сторонних зависимостей нет.

## Инженерная часть

- CI на Linux, Windows и macOS: тесты на GoogleTest и побайтовое сравнение с эталонным файлом; отдельная задача гоняет всё под санитайзерами.
- Каждый коммит, прошедший CI, получает тег семантической версии и GitHub Release с собранными библиотеками.
- В CMake-проект библиотека подключается через `CPMAddPackage`; в README — сравнение по возможностям с pyvcd и cpp-vcd-tracer.
