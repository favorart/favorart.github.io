Se describe un lenguaje de programación interpretado con sintaxis modificable y su intérprete. La principal característica del lenguaje es que el aspecto del código fuente se aproxima al máximo a un texto formal (por ejemplo, matemático) en ruso. Para ello se desarrollaron un analizador léxico no limitado a nombres y operadores de una sola palabra, un analizador sintáctico con configuración flexible de la sintaxis y la semántica, un conjunto de palabras clave que el usuario puede reemplazar (incluso traduciéndolo a otro idioma), la precompilación del código y unos tipos enumerados replanteados. Un lenguaje así facilita el aprendizaje y el mantenimiento de los programas, así como el entendimiento mutuo entre el programador y el cliente, que puede leer el código por sí mismo y comprobar que el programa hace lo que debe.
