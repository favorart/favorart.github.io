Se ha desarrollado un algoritmo de aprendizaje para el problema del posicionamiento de sistemas con control discreto, basado en un método de generalización de los ensayos y errores almacenados en una base de datos mediante interpolación global y descenso de gradiente. El algoritmo se optimiza según el criterio de reducción del tiempo de aprendizaje (número de intentos). El algoritmo se ha probado en un simulador con modelos de sistemas que actúan en el plano, de dos tipos distintos: un robot móvil con dos orugas motrices y una cadena cinemática abierta con articulaciones de rotación y prismáticas.
