# favorart.github.io

Personal page of Kirill Golikov: https://favorart.github.io

The site is generated by `build.py` (Python + `markdown`, `pyyaml`, `pygments`) and deployed by
GitHub Actions (`.github/workflows/pages.yml`) on every push to `main`, daily, and on manual run.

## Layout

| Path | What |
|---|---|
| `content/home.en.html` | home page body (sections, CV preview, contact form) |
| `content/cv.en.html` | the full CV page `/cv/` |
| `i18n/en.yml` | UI strings; one file per language (`prefix: /ru` etc. for non-default ones) |
| `templates/` | base layout and partials — the design lives here and in `assets/site.css` |
| `assets/site.css` | the one stylesheet |
| `posts/<yyyy-mm-slug>/index.md` | LinkedIn posts (+ their images in the same folder) |
| `sources.yml` | external articles and courses, pulled from other repos at build time |
| `covers/<slug>/` | cover options for external content; chooser page: `/writing/covers/` |
| `tools/make_covers.py` | generates 3 SVG cover options |
| `tools/check_links.py` | checks the built site for broken links/images |

## Build locally

```sh
pip install -r requirements.txt
python build.py            # -> _site/  (add --offline to skip fetching external repos)
python tools/check_links.py _site
python -m http.server -d _site 8000
```

## Add a LinkedIn post

1. Create a folder `posts/2026-12-short-slug/` (the page will be `/writing/short-slug/`).
2. Put `index.md` there:

   ```markdown
   ---
   title: "Post headline"
   date: 2026-12-01
   lang: ru
   summary: "One or two sentences for the card."
   source: linkedin
   original_url: https://www.linkedin.com/posts/...
   cover: cover.jpg          # an image in this folder; omit and run tools/make_covers.py for SVG options
   tags: [cpp, performance]  # optional, the post's hashtags
   ---

   Post text in Markdown. Images: ![alt](picture.png) with picture.png in this folder.
   ```

   Note: a line starting with `#word` is a heading in Markdown — write `\#word` for a hashtag.
3. Commit and push — the Action rebuilds the site.

## Add an external article or course

Add an entry to `sources.yml` (`articles:` → `/writing/<slug>/`, `courses:` → `/courses/<slug>/`)
with `repo`, `branch`, `path`, `title`, `date`, `summary`. Nothing is copied: the Markdown is fetched at
build time and its relative links/images point back to the source repo. For a cover run
`python tools/make_covers.py covers/<slug> <motif> "<title>" "<kicker>"` (motifs: pi, robot, tree, cpp,
cpu, code), set `cover: covers/<slug>/cover-1.svg`, then pick the final option on `/writing/covers/`.
